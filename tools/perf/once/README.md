# 一次性诊断探针(保留,可复核)

这里的每个脚本都是**为了回答一个具体的疑问**临时写出来的,问完就留着不再改。
它们不是回归测试 —— 没有断言、没有通过/失败,只打印原始数据。

**留着的原因是"读数可复核"**:正式探针(`probe_ui.mjs`、`probe_mobile.mjs`)的
注释里引用了它们量到的原始数字。看报告的人如果怀疑某个结论,可以照着注释里的
文件名把当时那台仪器原样再跑一遍,而不是只能相信结论。

它们当初都叫 `_tmp_*.mjs`,那个名字是**错的** —— 前缀写着"待删",可它们
已经成了证据链的一环。删掉它们等于让注释里那些引用变成指向空气的话。

| 脚本 | 当初要回答的问题 | 结论落在哪儿 |
|---|---|---|
| `pe.mjs` | 加载遮罩里那些元素的 `pointer-events` 到底是谁在挡谁? | `probe_ui.mjs` ⑦ 的注释(`button.qm-label` 的继承链) |
| `stab.mjs` | 漫游速度的"尖刺"是真的,还是我的秒表错了? | `probe_ui.mjs` ⑧ 的注释(三个时钟:rAF 戳 / `performance.now()` / 回调落点) |
| `touch.mjs` | CDP 派发的触摸事件到底有没有进到页面里? | `probe_mobile.mjs` ④⑤ 的注释(事件序列与拖动起手点) |
| `covr.mjs` | 窄屏屏幕中央那片被谁盖住了? | `probe_mobile.mjs` ⑤ 的注释(标签是 `.qm-interactive` 孤岛) |
| `panels.mjs` | 两个面板能不能同时开着? | `probe_mobile.mjs` 的注释(单面板不变量成立,错的是我的仪器) |
| `boat_diag.mjs` | 船壳到底在转**它自己**吗?船上的静态件跟着走了吗? | `probe_ui.mjs` ⑤ 的注释(**两次**仪器错:量了原点不是材质点;力臂量到轴心不是轴线) |
| `b1_catch.mjs` | `effects.mjs` B1 那几百个差异像素**是什么**? | `docs/10-阶段验收记录.md`「未定项」(54 轮 0 复现;**成因未定**) |
| `fx_settle.mjs` | 差异是"第一帧异类"还是"帧帧都在变"? | 同上(停循环后连拍 8 帧,0 像素差异;排除了"首帧"这支) |

## 已删:ids_tmp.mjs

它是这里唯一**没人引用**的一个 —— 没有注释、没有报告、没有 memory 提过它。
按上面那条留住它们的理由(读数可复核),它没有资格留下;而它的名字自己写着
"临时"。删掉它不会让任何一句话变成指向空气的话,这一条是核对过的(全仓库 +
memory 目录各搜了一遍文件名)。

## 跑法

和正式探针一样,先起服务再喂 URL:

```bash
node scripts/serve-dist.mjs --dir dist --port 4173 &
node tools/perf/once/stab.mjs http://127.0.0.1:4173/
```

⚠️ 它们**不会**自己起服务,也**不会**自己写 json。这是刻意的:一次性探针的
输出是给人看的,给人看的东西不需要接口。
